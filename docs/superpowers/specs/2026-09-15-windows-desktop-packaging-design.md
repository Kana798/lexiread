# Windows 桌面版封装设计

## 目标

将 LexiRead 封装为 Windows 10/11 桌面应用。用户可选择安装版或便携版，在未安装 Node.js 的电脑上运行完整阅读器功能。

## 范围

- 输出 NSIS 安装包和单文件便携版 `.exe`。
- 使用 Electron 提供浏览器窗口与内置 Node.js 运行时。
- 保留现有 Express API、PDF 导入、文本修复、语音朗读和有道联网翻译。
- 用户通过现有设置页面配置可选的大模型；不会把开发机 `.env` 中的密钥打入发行包。

## 架构

1. `electron/main.cjs` 是桌面入口。
2. 入口在可用的本地回环端口启动已构建的 Express 服务，并指定生产模式。
3. Electron 等待本地 `/api/health` 返回成功后，创建仅加载该本地地址的 `BrowserWindow`。
4. 用户关闭最后一个窗口时，桌面入口停止本地服务并退出。
5. Electron Builder 将前端构建产物、服务端构建产物和生产依赖一起放入应用资源；不包含 `.env`、源码测试和开发依赖。

## 构建与发布

- `npm run build` 继续生成 `dist/` 中的网页与服务端产物。
- `npm run desktop:pack` 构建 Windows 发布物，不生成安装程序，供本地检查。
- `npm run desktop:dist` 构建 NSIS 安装包与便携版可执行文件，输出到 `release/`。
- 发行物使用 `LexiRead` 作为应用名称。未配置代码签名时，Windows 可能展示未知发布者提示；这不影响功能。

## 数据与联网

- 用户文章、词汇和阅读设置继续保存于应用的浏览器本地存储中。
- 有道联网翻译仍通过本地服务请求其官方接口，因此目标电脑需要网络。
- 发行版不携带开发机凭据。若要启用服务端有道凭据，可在安装目录旁放置用户自行维护的 `.env`；这属于用户本地配置，不进入安装包。

## 错误处理

- 若本地服务未能启动或健康检查失败，显示桌面错误对话框并退出，不显示空白窗口。
- 若端口被占用，入口自动改用新的可用回环端口。
- 服务意外退出时，窗口显示明确错误页，避免继续向不可用 API 发请求。

## 验证

- 对桌面入口的端口、服务就绪与退出清理逻辑编写单元测试。
- 运行现有全部测试、类型检查和网页构建。
- 构建安装版与便携版，检查输出文件存在。
- 在本机启动便携版，验证本地健康检查与主窗口加载成功。
